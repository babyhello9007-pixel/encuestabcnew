# Validación visual — Exportación de candidato y filtro temporal del Sankey

Fecha de comprobación: 22 de agosto de 2026.

El modal de evolución presenta el botón **Exportar PNG**, la serie acumulada y sus ocho hitos. El Sankey muestra un selector de fechas con el intervalo aplicado, la acción para limpiar fechas y un mensaje que confirma que utiliza las respuestas registradas en ese periodo. La descarga de historial se validará mediante una interacción de puntero real para preservar el gesto de descarga del navegador.
